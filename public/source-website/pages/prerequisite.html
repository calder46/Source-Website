    Import official course and transfer data (JSON)

    There is no connected official API or automatic import configured. Select a normalized JSON export to validate it and save it in this browser only. Validation checks structure and source URLs, not the truth of claims; verification labels come from the import and must be confirmed against their linked sources.

    Required JSON format

    This schema illustration is not course data. Use four top-level arrays: courses, prerequisiteRules, sendingInstitutions, and transferEquivalencies. Each record needs a unique id, source institution, source URL, import date, and verification status. Read the complete JSON import contract and update instructions.

    {
  "courses": [{
    "id": "lib-course-unique-id",
    "courseCode": "CSIS 212",
    "title": "Official title",
    "description": "Official catalog description",
    "creditHours": 3,
    "department": "Department name",
    "catalogUrl": "https://catalog.liberty.edu/...",
    "catalogYear": "2026-2027",
    "lastVerifiedDate": "2026-10-27",
    "prerequisitesStatus": "documented",
    "sourceInstitution": "Liberty University",
    "sourceUrl": "https://catalog.liberty.edu/...",
    "importedAt": "2026-10-27",
    "verificationStatus": "official-needs-confirmation"
  }],
  "prerequisiteRules": [{
    "id": "rule-unique-id",
    "courseId": "lib-course-unique-id",
    "prerequisiteCourseId": "another-lib-course-id",
    "ruleGroupId": "required-or-alternative-group",
    "relationshipType": "AND",
    "minimumGrade": "C",
    "sourceInstitution": "Liberty University",
    "sourceUrl": "https://catalog.liberty.edu/...",
    "importedAt": "2026-10-27",
    "verificationStatus": "official-needs-confirmation"
  }],
  "sendingInstitutions": [],
  "transferEquivalencies": []
}

    Use AND for required rules; rules sharing a group with OR represent permitted alternatives. Transfer rows reference course and institution IDs. Status values are verified-liberty-guide, official-needs-confirmation, and unverified-suggestion.
